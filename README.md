🤖 AI Auto Reply Chatbot

A Python-based automated chatbot that reads chat messages, generates suitable replies based on predefined conversation patterns, and automatically sends the response.

✨ Features

- 💬 Automatic chat message detection
- 🤖 Smart rule-based reply generation
- 👋 Greeting and casual conversation responses
- 📚 Study and exam-related responses
- 💻 Work and project-related responses
- 📋 Automatic copy and paste functionality
- 📤 Automatically sends generated replies
- 🔄 Continuously monitors the chat
- 🛡️ Handles errors without immediately stopping
- ⚡ Offline demo mode — no API key required

🛠️ Technologies Used

- Python
- PyAutoGUI
- Pyperclip
- Time Module

📦 Required Python Packages

The following packages are required:

pip install pyautogui pyperclip

Built-in Python Modules

These modules are already included with Python and do not require separate installation:

- "time"

🧠 How It Works

The chatbot reads the selected chat history and analyzes the text using predefined rules.

Based on the detected keywords or phrases, it generates an appropriate response and automatically copies, pastes, and sends the reply through the chat application.
